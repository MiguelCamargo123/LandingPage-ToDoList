# LandingPage-ToDoList

## About

This project is a simple landing page for a To-Do List application.
It was created to present the idea of the app in a clean and minimal interface using only basic web technologies.

## Features

* Clean and simple landing page layout
* Responsive design
* Modern and minimal visual style
* Built with pure HTML and CSS

## Usage

1. Download or clone the repository.
2. Open the `index.html` file in your browser.
3. View the landing page.

## Version

Current version: **1.0.0**
